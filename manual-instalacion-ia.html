🛠️ Manual de Instalación — IA Local (ZeratnaPC)

Guía paso a paso para instalar todo el stack de IA local en el PC de Aaron: Ollama + VS Code + modelos de código + modelos de video + MCP Lore Server + Agente Orquestador. Sin créditos, sin nubes, sin límites.

Hardware target: RTX 3060 12GB | Ryzen 5 5600X | 16GB RAM DDR4 3200

Tiempo estimado: 30-45 minutos (+ tiempo de descarga de modelos)

📋 Hardware de ZeratnaPC

ComponenteSpecImpacto IA
CPURyzen 5 5600X (6C/12T)Excelente para offload a CPU
GPURTX 3060 12GB12GB VRAM = modelos MoE grandes
RAM16 GB DDR4 3200 (2×8GB)Suficiente para modelos + OS
MoboASRock B550M Pro4Expandible a 128GB si quiere

Ventaja clave: Los 12GB de VRAM permiten correr modelos MoE como qwen3-coder:30b que solo activa 3.3B parámetros por consulta — calidad de modelo grande, velocidad de modelo chico.

🔧 Paso 1 — Instalar Ollama

Ollama es el runtime que corre los modelos de IA localmente. Piensa en él como un "Docker para LLMs".

  1. Descarga desde ollama.com/download
  2. Ejecuta el instalador (siguiente, siguiente, listo)
  3. Verifica en terminal: ollama --version
  4. El servicio se inicia automáticamente en http://localhost:11434

O usa el script automático: SETUP_COMPLETO.ps1 (incluido abajo)

🤖 Paso 2 — Descargar Modelos

💻 Modelo para Programar

ModeloTamañoPara quéVRAM real
qwen3-coder:30b ⭐19 GB discoCódigo (MoE: solo 3.3B activos por consulta)~4-6 GB
qwen2.5-coder:7b4.7 GBAlternativa si algo falla~6 GB

¿Por qué qwen3-coder:30b en una 3060? Es MoE (Mixture of Experts) — tiene 30B parámetros totales pero solo activa 3.3B por consulta. Eso significa que en VRAM solo carga lo que necesita. 92.7% en HumanEval, mejor que muchos modelos de 70B. Pesa 19GB en disco pero en VRAM usa ~4-6GB activos.

ollama pull qwen3-coder:30b

📖 Modelo para Escribir/Narrativa

ModeloTamañoPara quéVRAM
gemma3:4b ⭐3 GBNarrativa rápida, deja VRAM libre~4 GB
gemma3:12b8.1 GBMejor calidad (pero usa casi toda la VRAM)~10 GB

Recomendado para tu setup: gemma3:4b — suficiente para prosa y diálogos, y te deja VRAM libre para tener otros modelos cargados. Si quieres máxima calidad narrativa, usa gemma3:12b pero cierra otros modelos primero.

ollama pull gemma3:4b
REM Para calidad superior (opcional):
ollama pull gemma3:12b

🎬 Modelo para Video

Para video local usamos Wan 2.1 (Alibaba) via ComfyUI. No se corre con Ollama sino con ComfyUI + Python.

VarianteTamañoVRAMCalidad
Wan2.1-T2V-1.3B ⭐ recomendado~3 GB8-10 GB480p, videos de 5s en ~2 min
Wan2.1-T2V-14B GGUF Q4 (nerfeado)~7 GB11-12 GB480p mejor calidad, ~5 min
Wan2.1-T2V-14B fp8 (NO cabe)~13 GB20-24 GB❌ No para RTX 3060

Para tu RTX 3060 12GB:

  • Opción A (recomendada): Wan2.1 1.3B — cabe perfecto, buena calidad 480p
  • Opción B (nerfeada): El 14B en formato GGUF Q4_K_M (~7GB) — calidad superior al 1.3B pero más lento. Configura: 480p, 24 frames, --lowvram

IMPORTANTE: Cuando uses ComfyUI para video, cierra Ollama primero (taskkill /f /im ollama.exe) para liberar toda la VRAM.

📚 Paso 4 — MCP Book Server (Asistente de Escritura)

El Book Server es tu asistente para escribir libros. Le pasás fuentes (PDFs, textos, notas) y te ayuda a estructurar, investigar y redactar.

Instalación:

  1. Crear carpeta: mkdir C:\IA-Local\book-server
  2. Instalar dependencias: pip install fastapi uvicorn python-docx PyPDF2 sentence-transformers
  3. Copiar el script book_server.py (incluido abajo)
  4. Ejecutar: python book_server.py
  5. Verificar: abrir http://localhost:8430/docs

Qué hace:

  • POST /fuentes/subir — sube un archivo (PDF, TXT, DOCX) como fuente de investigación
  • GET /fuentes — lista todas las fuentes cargadas
  • GET /fuentes/buscar?query=... — busca en las fuentes por keywords
  • GET /estructura — devuelve la estructura actual del libro (índice)
  • POST /estructura — define/actualiza la estructura (capítulos, secciones)
  • GET /capitulo/{num} — obtiene un capítulo escrito
  • POST /capitulo/{num} — guarda un capítulo generado/editado
  • GET /contexto/{capitulo} — genera contexto RAG de las fuentes relevantes para un capítulo
  • GET /resumen — resumen del estado del libro (caps escritos, pendientes, palabras totales)

Flujo de uso:

  1. Subís tus fuentes (PDFs de investigación, notas, artículos)
  2. Definís la estructura del libro (título, capítulos, temas por capítulo)
  3. Pedís al modelo que escriba un capítulo — el server inyecta automáticamente las fuentes relevantes como contexto
  4. Revisás, editás, guardás

🧠 Paso 4b — Entrenar tu IA para tu estilo

Podés entrenar (fine-tune) un modelo para que escriba con tu estilo personal. Necesitás ejemplos de tu escritura.

Preparar dataset:

REM 1. Crear archivo de entrenamiento (JSONL)
REM Formato: {"prompt": "instrucción", "completion": "tu texto escrito"}
REM Ejemplo:

{"prompt": "Escribe un párrafo introductorio sobre la revolución industrial", "completion": "Tu párrafo aquí con tu estilo..."}
{"prompt": "Describe el impacto social de la tecnología", "completion": "Tu descripción con tu tono..."}

REM Mínimo 50-100 pares para buenos resultados
REM Guardar como: C:\IA-Local\training\mi_estilo.jsonl

Comandos de entrenamiento:

REM === OPCION A: Crear Modelfile personalizado (rápido, sin GPU training) ===
REM Esto NO entrena de verdad, pero le inyecta tu estilo como system prompt

REM 1. Crear Modelfile
echo FROM gemma3:12b > C:\IA-Local\Modelfile.mi-escritor
echo PARAMETER temperature 0.8 >> C:\IA-Local\Modelfile.mi-escritor
echo PARAMETER num_ctx 32768 >> C:\IA-Local\Modelfile.mi-escritor
echo SYSTEM "Eres un escritor con este estilo: [PEGA AQUÍ 3-4 PÁRRAFOS DE EJEMPLO DE TU ESCRITURA]. Imita este tono, vocabulario y estructura en todo lo que escribas." >> C:\IA-Local\Modelfile.mi-escritor

REM 2. Crear modelo
ollama create mi-escritor -f C:\IA-Local\Modelfile.mi-escritor

REM 3. Probar
ollama run mi-escritor "Escribe un párrafo sobre [tu tema]"
REM === OPCION B: Fine-tune real con LoRA (necesita Python + GPU) ===
REM Más lento pero resultados mucho mejores

REM 1. Instalar dependencias de training
pip install transformers peft datasets accelerate bitsandbytes

REM 2. Crear script de entrenamiento (ver train_escritor.py abajo)
python train_escritor.py --dataset mi_estilo.jsonl --epochs 3 --model gemma-3-4b

REM 3. Exportar a Ollama
python export_to_ollama.py --output mi-escritor-trained

REM 4. Probar
ollama run mi-escritor-trained "Escribe sobre [tu tema]"

Tips de entrenamiento:

  • Opción A (Modelfile con system prompt): Instantáneo, sin training. Funciona sorprendentemente bien si le pasás buenos ejemplos de tu estilo. Empieza por aquí.
  • Opción B (LoRA fine-tune): Requiere 30-60 min de GPU. Resultados superiores pero necesitás 50+ ejemplos de tu escritura.
  • Dataset mínimo: 50 pares prompt/completion. Más es mejor.
  • Modelo base: gemma3:4b para fine-tune rápido, gemma3:12b para Modelfile con system prompt.
  • Tu RTX 3060 12GB puede fine-tunear modelos de hasta 4B parámetros con LoRA 4-bit.

🧠 Paso 5 — Agente Orquestador de Escritura

El orquestador es tu asistente inteligente desde terminal. Le decís en lenguaje natural qué necesitás y él clasifica, busca en tus fuentes, genera texto, y te lo entrega.

Descargar:

cd /d C:\Users\juaro\OneDrive\Documents\Zeratna\book-server
curl -o orquestador_escritor.py https://raw.githubusercontent.com/marbaezf-tech/plaga-wiki/main/orquestador_escritor.py

Ejecutar:

python orquestador_escritor.py

Comandos que entiende:

DecísHace
escribe cap 1Genera el capítulo 1 usando tus fuentes como contexto
edita cap 2Mejora/reescribe un capítulo ya escrito
busca revolución industrialBusca en tus PDFs/fuentes cargadas
estructuraDefine el índice del libro (interactivo)
estadoMuestra progreso (capítulos escritos, pendientes, palabras)
(cualquier pregunta)Se la pasa al modelo directo

Personalización — edita la sección MODELOS en el script:

# Modelos — cambia según lo que tengas instalado
MODELOS = {
    "escritura": "gemma3:12b",        # Para escribir prosa (o gemma3:4b si poca VRAM)
    "clasificador": "qwen3:4b",       # Para clasificar tareas (rápido)
    "investigacion": "qwen2.5:7b",    # Para analizar/resumir fuentes
    "edicion": "gemma3:12b",          # Para editar/mejorar texto
}

# Si tu RTX 3060 se queda sin VRAM, cambia gemma3:12b por gemma3:4b

Flujo completo de trabajo:

  1. Levantá el Book Server: python book_server.py
  2. Subí tus fuentes (PDFs, textos) via http://localhost:8430/docs
  3. Ejecutá el orquestador: python orquestador_escritor.py
  4. Definí estructura: estructura
  5. Escribí capítulos: escribe cap 1, escribe cap 2...
  6. Revisá y editá: edita cap 1

🎬 Paso 6 — ComfyUI para Video (Wan 2.1)

  1. Descarga ComfyUI portable (Windows)
  2. Extrae en C:\ComfyUI\
  3. Descarga los modelos de Wan 2.1:
    • Ligero: Wan2.1-T2V-1.3B → ComfyUI\models\diffusion_models\
    • Superior: Wan2.1-T2V-14B-fp8 → misma carpeta
  4. Descarga el VAE y text encoder (links en HuggingFace)
  5. Ejecuta run_nvidia_gpu.bat
  6. Abre http://127.0.0.1:8188

Para "nerfear" el modelo 14B (correr en 12GB VRAM):

  • Usar la versión GGUF Q4_K_M (~7GB en lugar de 13GB)
  • Bajar resolución a 480p en lugar de 720p
  • Reducir frames (24 en lugar de 48)
  • Usar --lowvram en ComfyUI

⚡ Script de Instalación Automática

El script SETUP_ZERATNA.ps1 instala y configura todo automáticamente. Ejecutar como Administrador en PowerShell.

⬇️ Descargar SETUP_ZERATNA.ps1

Cómo usarlo:

REM 1. Click derecho en PowerShell → "Ejecutar como administrador"
REM 2. Navegar a donde descargaste el archivo:
cd C:\Users\TU_USUARIO\Downloads

REM 3. Permitir ejecución y correr:
Set-ExecutionPolicy Bypass -Scope Process -Force
.\SETUP_ZERATNA.ps1

El script hace:

  1. ✅ Verifica tu GPU/RAM/disco
  2. ✅ Instala Ollama (si no está)
  3. ✅ Descarga 4 modelos optimizados para RTX 3060 12GB
  4. ✅ Instala Python + dependencias
  5. ✅ Configura VS Code con Continue (3 modelos + autocomplete)
  6. ✅ Crea el Agente Orquestador con config personalizable
  7. 📋 Te da instrucciones para ComfyUI + Wan 2.1

Después del script, prueba que funciona:

python C:\IA-Local\orquestador\test_rapido.py

💡 Tips para RTX 3060 12GB

  • No corras 2 modelos grandes al mismo tiempo. Ollama maneja la cola automáticamente pero si cargas código + video = 💥
  • Cierra Chrome antes de generar video. Chrome come VRAM para hardware acceleration
  • qwen3-coder:30b es tu mejor amigo. Es MoE — calidad de modelo de 30B, velocidad de modelo de 4B
  • Para video: cierra todo. ComfyUI + Wan 2.1 quiere los 12GB para él solo
  • El autocomplete (qwen3:4b) es instantáneo. Solo usa 3GB, puede correr de fondo sin problema
  • Si un modelo va lento: Ollama está haciendo offload a CPU (16GB RAM). Es normal — el Ryzen 5600X es bueno en esto
