🛠️ Manual de Instalación — IA Local (ZeratnaPC)

Guía paso a paso para instalar todo el stack de IA local en el PC de Aaron: Ollama + VS Code + modelos de código + modelos de video + MCP Lore Server + Agente Orquestador. Sin créditos, sin nubes, sin límites.

Hardware target: RTX 3060 12GB | Ryzen 5 5600X | 16GB RAM DDR4 3200

Tiempo estimado: 30-45 minutos (+ tiempo de descarga de modelos)

📋 Hardware de ZeratnaPC

ComponenteSpecImpacto IA
CPURyzen 5 5600X (6C/12T)Excelente para offload a CPU
GPURTX 3060 12GB12GB VRAM = modelos MoE grandes
RAM16 GB DDR4 3200 (2×8GB)Suficiente para modelos + OS
MoboASRock B550M Pro4Expandible a 128GB si quiere

Ventaja clave: Los 12GB de VRAM permiten correr modelos MoE como qwen3-coder:30b que solo activa 3.3B parámetros por consulta — calidad de modelo grande, velocidad de modelo chico.

🔧 Paso 1 — Instalar Ollama

Ollama es el runtime que corre los modelos de IA localmente. Piensa en él como un "Docker para LLMs".

  1. Descarga desde ollama.com/download
  2. Ejecuta el instalador (siguiente, siguiente, listo)
  3. Verifica en terminal: ollama --version
  4. El servicio se inicia automáticamente en http://localhost:11434

O usa el script automático: SETUP_COMPLETO.ps1 (incluido abajo)

🤖 Paso 2 — Descargar Modelos

💻 Modelo para Programar

ModeloTamañoPara quéVRAM real
qwen3-coder:30b ⭐19 GB discoCódigo (MoE: solo 3.3B activos por consulta)~4-6 GB
qwen2.5-coder:7b4.7 GBAlternativa si algo falla~6 GB

¿Por qué qwen3-coder:30b en una 3060? Es MoE (Mixture of Experts) — tiene 30B parámetros totales pero solo activa 3.3B por consulta. Eso significa que en VRAM solo carga lo que necesita. 92.7% en HumanEval, mejor que muchos modelos de 70B. Pesa 19GB en disco pero en VRAM usa ~4-6GB activos.

ollama pull qwen3-coder:30b

📖 Modelo para Escribir/Narrativa

ModeloTamañoPara quéVRAM
gemma3:4b ⭐3 GBNarrativa rápida, deja VRAM libre~4 GB
gemma3:12b8.1 GBMejor calidad (pero usa casi toda la VRAM)~10 GB

Recomendado para tu setup: gemma3:4b — suficiente para prosa y diálogos, y te deja VRAM libre para tener otros modelos cargados. Si quieres máxima calidad narrativa, usa gemma3:12b pero cierra otros modelos primero.

ollama pull gemma3:4b
REM Para calidad superior (opcional):
ollama pull gemma3:12b

🎬 Modelo para Video

Para video local usamos Wan 2.1 (Alibaba) via ComfyUI. No se corre con Ollama sino con ComfyUI + Python.

VarianteTamañoVRAMCalidad
Wan2.1-T2V-1.3B ⭐ recomendado~3 GB8-10 GB480p, videos de 5s en ~2 min
Wan2.1-T2V-14B GGUF Q4 (nerfeado)~7 GB11-12 GB480p mejor calidad, ~5 min
Wan2.1-T2V-14B fp8 (NO cabe)~13 GB20-24 GB❌ No para RTX 3060

Para tu RTX 3060 12GB:

  • Opción A (recomendada): Wan2.1 1.3B — cabe perfecto, buena calidad 480p
  • Opción B (nerfeada): El 14B en formato GGUF Q4_K_M (~7GB) — calidad superior al 1.3B pero más lento. Configura: 480p, 24 frames, --lowvram

IMPORTANTE: Cuando uses ComfyUI para video, cierra Ollama primero (taskkill /f /im ollama.exe) para liberar toda la VRAM.

💻 Paso 3 — Configurar VS Code

  1. Instala VS Code
  2. Instala la extensión Continue (sidebar: IA local con Ollama)
  3. Configura Continue para usar tu modelo local:

Archivo ~/.continue/config.json:

{
  "models": [
    {
      "title": "Qwen3 Coder (Local)",
      "provider": "ollama",
      "model": "qwen3-coder:30b",
      "systemMessage": "You are an expert Godot/GDScript developer assistant. All internal reasoning must be in English. Your final direct communication with the user MUST ALWAYS be strictly in Spanish. NUNCA me respondas en inglés. EXCEPTIONS: Technical names, file names, functions, nodes, APIs, paths, code blocks, and error logs remain in their original language. Be direct and concise. Skip filler phrases. Assume Godot Engine 4.6 + GDScript unless specified otherwise."
    },
    {
      "title": "Gemma3 Escritor (Local)",
      "provider": "ollama",
      "model": "gemma3:12b"
    }
  ],
  "tabAutocompleteModel": {
    "title": "Qwen3 Autocomplete",
    "provider": "ollama",
    "model": "qwen3-coder:30b"
  }
}

🪲 Paso 4 — MCP Lore Server

El Lore Server expone los datos canónicos del juego (NPCs, taxones, facciones) como una API REST que los modelos pueden consultar.

  1. Clonar el repo: git clone https://github.com/marbaezf-tech/la-descarada.git
  2. Instalar dependencias: pip install fastapi uvicorn
  3. Ejecutar: python mcp-lore/http_bridge.py
  4. Verificar: abrir http://localhost:8420/docs

El servidor expone endpoints como:

  • /npc/{nombre} — ficha completa de un NPC
  • /taxon/{query} — stats de un taxón
  • /lore?tema=... — búsqueda en lore fundacional
  • /contexto/{categoria}?query=... — texto formateado para inyectar en prompts

🧠 Paso 5 — Agente Orquestador

El orquestador es tu "Kiro local" — clasifica la tarea, elige el modelo correcto, genera, valida, y te entrega resultado limpio.

# Ejecutar
cd descarada/orquestador
python orquestador.py

# O con el BAT
INICIAR_ORQUESTADOR.bat

Personalización: Edita config.py para:

  • Cambiar modelos por rol (clasificador, código, narrativa, lore, validador)
  • Ajustar umbrales de complejidad
  • Modificar la regla de idioma
  • Configurar el MCP Lore Server URL

Ejemplo de config.py personalizable:

MODELOS = {
    "clasificador": "qwen3:4b",        # Rápido, clasifica complejidad
    "codigo": "qwen3-coder:30b",       # Tu modelo de código preferido
    "narrativa": "gemma3:12b",         # Prosa y diálogos
    "lore": "qwen3:8b",               # Lore del juego
    "validador": "qwen3:4b",          # Valida output (rápido)
    "fallback": "qwen2.5:7b",         # Si falla algo
}

# Cambia esto según tu proyecto:
LORE_SERVER_URL = "http://localhost:8420"

🎬 Paso 6 — ComfyUI para Video (Wan 2.1)

  1. Descarga ComfyUI portable (Windows)
  2. Extrae en C:\ComfyUI\
  3. Descarga los modelos de Wan 2.1:
    • Ligero: Wan2.1-T2V-1.3B → ComfyUI\models\diffusion_models\
    • Superior: Wan2.1-T2V-14B-fp8 → misma carpeta
  4. Descarga el VAE y text encoder (links en HuggingFace)
  5. Ejecuta run_nvidia_gpu.bat
  6. Abre http://127.0.0.1:8188

Para "nerfear" el modelo 14B (correr en 12GB VRAM):

  • Usar la versión GGUF Q4_K_M (~7GB en lugar de 13GB)
  • Bajar resolución a 480p en lugar de 720p
  • Reducir frames (24 en lugar de 48)
  • Usar --lowvram en ComfyUI

⚡ Script de Instalación Automática

El script SETUP_ZERATNA.ps1 instala y configura todo automáticamente. Ejecutar como Administrador en PowerShell.

⬇️ Descargar SETUP_ZERATNA.ps1

Cómo usarlo:

REM 1. Click derecho en PowerShell → "Ejecutar como administrador"
REM 2. Navegar a donde descargaste el archivo:
cd C:\Users\TU_USUARIO\Downloads

REM 3. Permitir ejecución y correr:
Set-ExecutionPolicy Bypass -Scope Process -Force
.\SETUP_ZERATNA.ps1

El script hace:

  1. ✅ Verifica tu GPU/RAM/disco
  2. ✅ Instala Ollama (si no está)
  3. ✅ Descarga 4 modelos optimizados para RTX 3060 12GB
  4. ✅ Instala Python + dependencias
  5. ✅ Configura VS Code con Continue (3 modelos + autocomplete)
  6. ✅ Crea el Agente Orquestador con config personalizable
  7. 📋 Te da instrucciones para ComfyUI + Wan 2.1

Después del script, prueba que funciona:

python C:\IA-Local\orquestador\test_rapido.py

💡 Tips para RTX 3060 12GB

  • No corras 2 modelos grandes al mismo tiempo. Ollama maneja la cola automáticamente pero si cargas código + video = 💥
  • Cierra Chrome antes de generar video. Chrome come VRAM para hardware acceleration
  • qwen3-coder:30b es tu mejor amigo. Es MoE — calidad de modelo de 30B, velocidad de modelo de 4B
  • Para video: cierra todo. ComfyUI + Wan 2.1 quiere los 12GB para él solo
  • El autocomplete (qwen3:4b) es instantáneo. Solo usa 3GB, puede correr de fondo sin problema
  • Si un modelo va lento: Ollama está haciendo offload a CPU (16GB RAM). Es normal — el Ryzen 5600X es bueno en esto
