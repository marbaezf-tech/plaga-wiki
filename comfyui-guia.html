🎨 ComfyUI — Generación de Arte Local

Guía para instalar y usar ComfyUI + Stable Diffusion como generador de imágenes local para Plaga: La Descarada. Concept art, sprites, retratos de NPCs, texturas, fondos — todo generado en tu GPU sin pagar API ni subir tu arte a la nube.

📋 ¿Qué es ComfyUI?

🖼️ Resumen

ComfyUI es una interfaz basada en nodos para ejecutar modelos de difusión (Stable Diffusion, FLUX, etc.) localmente. Funciona como un "Unreal Blueprints pero para generar imágenes". Expone una API REST en localhost:8188 que permite generar imágenes desde scripts o desde esta wiki.

  • Node-based — pipelines visuales flexibles
  • API REST — integrable con el juego y la wiki
  • LoRA training — entrenar tu propio estilo visual
  • 100% local — sin suscripciones ni límites

Hardware (tu PC)

GPURTX 3060 Ti (8 GB VRAM) ✅
Modelos soportadosSDXL, SD 1.5, FLUX.1 Dev (con offloading)
Resolución512×512 a 1024×1024
Tiempo por imagen~10-30 segundos (SDXL, 20 steps)
Espacio~7 GB por modelo checkpoint

📥 Instalación en Windows

Método Portable (Recomendado)

1Ir a GitHub Releases de ComfyUI
2Descargar ComfyUI_windows_portable_nvidia.7z
3Extraer en D:\ComfyUI\ (necesitas ~15 GB libres)
4Ejecutar run_nvidia_gpu.bat
5Abrir http://localhost:8188 en el navegador

Descargar modelo SDXL

Después de instalar ComfyUI, necesitas un modelo. Descarga uno de estos en ComfyUI/models/checkpoints/:

🌐 API REST — Generar desde la Wiki

📡 Endpoints principales

ComfyUI sirve su API en http://localhost:8188. Se puede enviar un workflow completo como JSON y recibir imágenes generadas.

Endpoints

MétodoEndpointDescripción
POST/promptEnviar workflow para generar imagen
GET/history/{prompt_id}Obtener resultado de generación
GET/view?filename=XDescargar imagen generada
POST/upload/imageSubir imagen (para img2img, ControlNet)
GET/object_infoLista todos los nodos disponibles
GET/system_statsEstado del sistema (VRAM, GPU)
WebSocketws://localhost:8188/wsProgreso en tiempo real

Ejemplo: Generar imagen vía API

# PowerShell — generar un concept art de insecto
$workflow = @{
    client_id = "plaga-wiki"
    prompt = @{
        "3" = @{
            class_type = "KSampler"
            inputs = @{
                seed = (Get-Random)
                steps = 20
                cfg = 7
                sampler_name = "euler_ancestral"
                scheduler = "normal"
                denoise = 1
                model = @("4", 0)
                positive = @("6", 0)
                negative = @("7", 0)
                latent_image = @("5", 0)
            }
        }
        # ... (workflow completo exportado desde ComfyUI)
    }
} | ConvertTo-Json -Depth 10

Invoke-RestMethod -Method POST -Uri "http://localhost:8188/prompt" `
    -Body $workflow -ContentType "application/json"

🧬 LoRA Visual — Entrenar tu propio estilo

🎨 ¿Qué es un LoRA de imagen?

Un pequeño archivo (~100-300 MB) que enseña al modelo a generar en un estilo específico. Entrenas con 20-50 imágenes de referencia y luego cada imagen que generes mantiene ese estilo consistente. Ideal para sprites del juego.

Flujo de entrenamiento LoRA visual

PasoQué hacerTiempo
1Recolectar 20-50 imágenes de referencia (tu concept art, estilo objetivo)Manual
2Etiquetar imágenes con tags (automático con WD Tagger o BLIP)~5 min
3Instalar Kohya_ss o usar LoRA Easy TrainingUna vez
4Configurar: 20 épocas, lr=1e-4, dim=32, batch=1~2 min
5Lanzar entrenamiento (dejar corriendo)~1-2 horas
6Copiar .safetensors resultante a ComfyUI/models/loras/~1 min
7Usar en workflow con nodo "LoRA Loader" (weight: 0.7-1.0)Listo

🔗 Integración con la Wiki

🚧 Próximamente

Una vez ComfyUI esté instalado, se habilitará un generador de imágenes integrado en esta wiki. Podrás escribir un prompt, generar la imagen, y guardarla directamente en img/ para usarla en las páginas de NPCs y taxones.

Pipeline completo (objetivo)

  1. Desde la wiki: escribir prompt + seleccionar estilo
  2. ComfyUI genera la imagen (localhost:8188)
  3. Preview en el navegador
  4. Si apruebas → guardar en wiki/img/ y godot/assets/sprites/
  5. Auto-asociar a NPC/taxón/zona correspondiente
