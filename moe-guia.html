🧠 MoE Router — Mixture of Experts

El Senior que delega al Junior correcto. Un router inteligente que analiza tu pregunta y la envía al modelo de IA más adecuado. No necesitas recordar qué modelo usar — el MoE decide por ti.

🚀 Cómo usar

Lanzar

MOE_PLAGA.bat

Espera a que cargue (muestra los modelos con ✅), luego escribe tu pregunta en el prompt 🪲 >

💻 Preguntas de Código (plaga-coder)

Lo que sabe de entrada (system prompt)

  • Toda la arquitectura del proyecto (autoloads, scripts, zonas)
  • APIs exactas: GameManager.inventario.append(), GameManager.ganar_exp()
  • Señales de DialogueTrigger: dialogo_iniciado(npc_id)
  • Convenciones: español, snake_case, signals tipadas Godot 4

Además lee los scripts del proyecto (48K chars de contexto)

game_manager.gd, main.gd, player.gd, combat_manager.gd, iso_map.gd, ai_npc_cache.gd, loot_system.gd, dialogue_trigger.gd

Ejemplos de prompts buenos

Implementa quest_system.gd como autoload. Debe conectarse con DialogueTrigger para activar quests al hablar con NPCs. Usa GameManager.inventario.append() para dar items. Solo el código.
Agrega un sistema de crafteo al GameManager. Items combinables: Hilo de Seda + Toxina = Trampa Venenosa. Usa el inventario existente.
Corrige combat_manager.gd para que la Danza de Antenas cueste 1 Instinto por intento

Tips para mejor resultado

  • Sé específico: "Implementa X" es mejor que "Haz algo para Y"
  • Menciona archivos: "como autoload", "en combat_manager.gd"
  • Menciona APIs: "Usa GameManager.inventario.append()"
  • Pide solo código: "Solo el código, sin explicación" evita que llene de texto
  • Dale tiempo: puede tardar 3-5 min, no cierres la ventana

📖 Preguntas Narrativas (plaga-narrator)

Lo que sabe de entrada

  • Las 4 facciones con descripción completa
  • Los 17 taxones con su personalidad
  • 37 NPCs clave con nombre y rol
  • Las 2 amenazas finales (Hormiga Reina + Díada Verde)
  • Mecánicas narrativas (Esencia, Atavismos, Danza de Antenas)
  • Tono: Ramazzottius, cínico, humor negro, prosa directa

Ejemplos de prompts

🔧 Arquitectura técnica

Cómo funciona internamente

  1. Clasificación: Analiza keywords + regex en tu pregunta → decide categoría (código/narrativa/lore)
  2. Tarea compuesta: Si detecta que necesita contexto de lore + código, encadena: primero consulta plaga-qwen3, luego pasa esa info a plaga-coder
  3. Inyección de contexto: Si es código, lee automáticamente los 8 scripts principales del proyecto (48K chars)
  4. Consulta Ollama: Envía todo al modelo elegido via ollama run
  5. Log: Guarda cada decisión en moe_router.log para mejorar el router

🎯 Cómo mejorar los resultados

Si el código inventa APIs que no existen:

Agregar la corrección al Modelfile.plaga-coder y recrear con ollama create plaga-coder -f Modelfile.plaga-coder

Si la narrativa no usa el lore correctamente:

Agregar el dato al Modelfile.plaga-narrator y recrear con ollama create plaga-narrator -f Modelfile.plaga-narrator

Si el router manda la pregunta al modelo equivocado:

Usar /forzar <modelo> <pregunta> o agregar keywords a moe_router.py
