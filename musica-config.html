🎸 Configuración de Audio — Line 6 POD HD500X

Guía completa de configuración de la pedalera para grabación y monitoreo del soundtrack/efectos de Plaga. Setup orientado a metal industrial (Ministry, Godflesh) directo a DAW.

🎛️ Equipamiento

Line 6 POD HD500X Ibanez Prestige RGR652AHBF WK (2025) ESP LTD TE-407 (7 cuerdas, activas) KZ ZS10 Pro X (in-ears) Interfaz de audio USB

⚡ Configuración Global de la POD HD500X

Estos ajustes se configuran UNA VEZ en el menú global de la pedalera (mantener presionado el botón VIEW) y aplican a TODOS los presets:

ParámetroValorPor qué
1/4" OutputLINESeñal a nivel de línea para la interfaz de audio
XLR OutputLINEMismo nivel si se usa XLR directo a consola
Output ModeStudio/DirectIncluye simulación completa de cabina + micrófono
⚠️ IMPORTANTE: En tu interfaz de audio, el input donde conectás la POD debe estar en modo LINE (no INST). Si lo dejás en INST, amplifica una señal que ya viene a nivel de línea y clipea digitalmente.

Cuándo cambiar estos valores

                                   Output interfaz → KZ ZS10 Pro X

🎛️ Cómo usar el HD500X Edit (Software de PC)

El software HD500X Edit es el editor visual para configurar presets desde la computadora. Aquí un resumen de la interfaz:

Zonas de la interfaz

ZonaUbicaciónFunción
Signal FlowCentro superior (fondo madera)Vista gráfica de la cadena de señal. Los cubos representan bloques de efecto/amp/cab
InputsEsquina superior izquierdaConfigurar Input 1/2 Source, Guitar In-Z, Inputs Setup
Send/ReceiveSuperior izquierdaEnviar/recibir presets entre PC ↔ pedalera
Tabs (FX/AMPS/MIXER/CONTROLLERS/SET LISTS)Centro, debajo del signal flowPaneles para editar distintos aspectos del preset
FX SlotsPanel derecho (con dropdowns)8 filas con FX TYPE y FX MODEL para asignar efectos
Preset ListPanel izquierdo inferiorLista de todos los presets del setlist actual

Configurar Input (primera vez)

1. En la esquina superior izquierda, cambiar Input 1 Source a Guitar
2. Input 2 Source: dejar en Same
3. Guitar In-Z: dejar en Auto
4. Inputs Setup: dejar en Preset

Agregar efectos a la cadena

Los efectos se asignan desde el panel derecho usando los dropdowns FX TYPE / FX MODEL. Cada fila corresponde a una posición en la cadena de señal:

1. Hacer click en el dropdown "FX TYPE" de una fila vacía → se despliegan categorías (Dynamics, Distortion, Modulation, Filter, EQ, Delay, Reverb, etc.)
2. Seleccionar la categoría deseada
3. Hacer click en "FX MODEL" de esa misma fila → se muestran los modelos disponibles
4. Seleccionar el modelo → aparece el bloque en el Signal Flow arriba
5. Hacer click en el bloque del Signal Flow para ver/editar sus parámetros

Agregar Amp + Cabina

1. Hacer click en la pestaña "AMPS" (arriba, al lado de FX)
2. Seleccionar el modelo de amplificador deseado de la lista
3. La cabina se asigna automáticamente junto al amp. Cambiar el modelo de cab y mic desde el mismo panel AMPS

Configurar el Mixer (Dual Path)

1. Hacer click en la pestaña "MIXER"
2. Ajustar volumen, paneo y mute de Path A y Path B

Crear Dual Path (Path A / Path B)

Para tener dos cadenas paralelas de señal (necesario para el preset industrial con Ring Mod):

1. En la pedalera física: presionar VIEW hasta llegar al Signal Flow View
2. Usar el D-pad para seleccionar un bloque de efecto
3. Presionar MOVE (doble press) y usar D-pad ↓ para mover al Path B
💡 TIP: El dual path es opcional. Los presets de esta guía funcionan perfectamente en single path (serie). El Path B solo agrega una capa sutil de textura industrial.

Guardar y Enviar a la Pedalera

1. Doble click en el nombre del preset en la lista izquierda → renombrar con el nombre de la tabla (ej: PLAGA INDUSTRL)
2. Ctrl+S o File → Save para guardar en el software
3. Click en "SEND → SELECTED" (arriba izquierda) para enviar el preset actual a la HD500X
4. Para enviar todo: "SEND → SET LIST" o "SEND → ALL"

🔊 PRESET 1: "PLAGA INDUSTRL" — Ibanez Prestige (Ministry/Godflesh)

Tono high-gain masivo con saturación abrasiva. Graves controlados pero pesados. Textura mecánica. Referencia: Ministry "N.W.O.", Godflesh "Streetcleaner".

Guitarra: Ibanez RGR652AHBF WK Humbuckers pasivas DiMarzio Fusion Edge

Cadena de señal (Single Path — serie)

Wah (EXP1) → Gate → Screamer → Amp (Line 6 Doom) + Cab (4x12 XXL V30) → EQ → Delay → Reverb

Paso a paso para configurar

SLOT 1 — Wah (controlado por EXP 1)
FX TYPE: Wah → FX MODEL: Fassel
Position: EXP 1 (pedal) Min: 0% Max: 100%
Controlado por el pedal EXP 1. Para sonido Ministry "Just One Fix": dejá el pedal fijo a 60% (mid-boost nasal agresivo). Para wah activo: mové el pedal. Para bypassear: apagalo con el toe-switch o FS asignado.
SLOT 2 — Noise Gate
FX TYPE: Dynamics → FX MODEL: Noise Gate
Threshold: 50% Decay: 0%
SLOT 3 — Screamer (boost)
FX TYPE: Distortion → FX MODEL: Screamer
Drive: 15% Bass: 35% Tone: 70% Level: 65%
Función: empuja el frente del amp con clip extra sucio. No es overdrive, es boost de ataque.
SLOT 4 — Amplificador
Tab: AMPS → Modelo: Line 6 Doom (basado en Sunn Model T)
Drive: 78% Bass: 50% Mid: 55% Treble: 52% Presence: 48% Ch. Vol: 55% Master: 85% Sag: 55% Bias: 60% Bias X: 55%
Master alto = compresión del power amp. Sag alto = respuesta lenta, spongey, pesada estilo doom.
SLOT 5 — Cabina
(Se asigna junto al amp en la pestaña AMPS)
Cab: 4x12 XXL V30 Mic: 421 Dynamic Distance: 35% E.R.: 0%
421 Dynamic da más cuerpo. Distance 35% = un poco de "room". E.R. a 0% = directo a DAW sin room mic.
SLOT 6 — EQ Paramétrico
FX TYPE: EQ → FX MODEL: Parametric EQ
LOWS: 38% HIGHS: 58% FREQ: 72% Q: 55% GAIN: 68%
LOWS <50% = corta graves. HIGHS >50% = sube agudos. FREQ apunta a ~1200 Hz (el "clang" metálico). GAIN >50% = boost en esa freq. 50% = flat en todo.
SLOT 7 — Delay
FX TYPE: Delay → FX MODEL: Analog Dly w/Mod
TEMPO SYNC: Off TIME: 375 ms FDBACK: 25% DEPTH: 30% MODSPD: 40% MIX: 20%
Delay analógico degradado y sucio. La modulación le da inestabilidad industrial.
SLOT 8 — Reverb
FX TYPE: Reverb → FX MODEL: Cave
Decay: 45% Mix: 15% Pre-delay: 60ms Tone: 40%
Espacio cavernoso tipo fábrica abandonada. Tone bajo = reverb oscura.

Asignación de pedales de expresión

PedalControlaEn este preset
EXP 1Wah (Fassel) — posición del filtroMover para wah activo. Fijar a 60% para sonido Ministry. Apagar para bypass.
EXP 2Volume Pedal (reservado para CORDYCEPS AMB)No se usa en este preset. Dejarlo al máximo.
💡 Tip Wah fijo: Para el sonido "Just One Fix" de Ministry, pisá el pedal EXP 1 hasta ~60% y dejalo ahí. Ese mid-boost nasal constante es la textura industrial. No necesitás moverlo — es un filtro estático.

Variantes por canción/estilo

Ministry — "Just One Fix"Agregar Wah fijo al 60% antes del Screamer

🔊 PRESET 2: "PLAGA 7STRING" — ESP LTD TE-407 (7 cuerdas)

Optimizado para cápsulas activas y la séptima cuerda. Menos ganancia (las activas saturan antes), graves más controlados para evitar embarrar en drop tunings.

Guitarra: ESP LTD TE-407 7 cuerdas — Activas

Cadena de señal (Single Path)

Gate → Amp (Line 6 Doom) + Cab (4x12 Tread V30) → EQ → Delay → Reverb
💡 Sin Screamer: Las pastillas activas ya pegan fuerte al preamp, no necesitan boost. Si querés más "tight", opcionalmente poné Screamer con Drive 0%, Level 50%.

Paso a paso

SLOT 1 — Noise Gate
FX TYPE: Dynamics → FX MODEL: Noise Gate
Threshold: 55% Decay: 0%
Threshold más alto que la Ibanez porque las activas tienen más output → más ruido residual.
SLOT 2 — Amplificador
Tab: AMPS → Modelo: Line 6 Doom
Drive: 55% Bass: 38% Mid: 65% Treble: 55% Presence: 60% Ch. Vol: 48% Master: 70% Sag: 20% Bias: 45% Bias X: 40%
MENOS drive (activas saturan antes). MENOS bass (la 7ma no embarre). MÁS mids (definición en drop). MENOS sag (respuesta rápida, tight).
SLOT 3 — Cabina
Cab: 4x12 Tread V30 Mic: 421 Dynamic Distance: 20%
SLOT 4 — EQ Paramétrico (CRÍTICO para 7 cuerdas)
FX TYPE: EQ → FX MODEL: Parametric EQ
LOWS: 30% HIGHS: 60% FREQ: 45% Q: 50% GAIN: 35%
LOWS muy bajo = corta sub-graves de la 7ma cuerda. FREQ apunta a ~500Hz, GAIN <50% = corta "boxy". HIGHS arriba = articulación pick attack.
SLOT 5 — Delay
FX TYPE: Delay → FX MODEL: Digital Delay
Time: 280ms Feedback: 12% Mix: 15%
SLOT 6 — Reverb
FX TYPE: Reverb → FX MODEL: Plate
Decay: 25% Mix: 10% Pre-delay: 40ms

💡 Tips por Guitarra

Ibanez Prestige RGR652AHBF WK

  • Pastillas DiMarzio Fusion Edge — output medio-alto, pasivas
  • Puente Gibraltar Standard III (2025)
  • Input Pad de la HD500X: OFF
  • El Screamer funciona bien como boost por el output moderado de las pasivas
  • Si falta pegada en palm mutes: subir Level del Screamer a 75%

ESP LTD TE-407 (7 cuerdas)

  • Cápsulas activas — output alto
  • Input Pad de la HD500X: ON (evita clipear el input)
  • NO necesita Screamer (las activas ya pegan duro al preamp)
  • Siempre bajar Bass y subir Mids vs. la config de 6 cuerdas
  • EQ post-amp: SIEMPRE cortar debajo de 80Hz para la 7ma cuerda
⚠️ Al alternar entre guitarras: Cambiar el Input Pad. ON para la ESP (activas), OFF para la Ibanez (pasivas). Si no, la Ibanez suena débil o la ESP clipea el input.

🎧 Tips para KZ ZS10 Pro X

Los KZ tienen un perfil de sonido con bump en graves y agudos (V-shape). Esto afecta cómo percibís el tono:

  • Si suena muy brillante por los in-ears: bajar Treble 3-5% en el amp. El tono "real" es lo que va a la DAW.
  • Si hay demasiado low-end: bajar Bass 3-5%. Es el bump de los KZ, no del preset.
  • Siempre mezclar/masterizar con monitores o referencias planas, NO con los KZ.

🔊 PRESET 4: "CORDYCEPS AMB" — Ibanez Prestige (Horror / Texturas enfermas)

Estilo Akira Yamaoka (Silent Hill 2: "White Noiz", "Null Moon", "Overdose Delusion"). Notas que aparecen como esporas, sin ataque. Disonancia constante, nada resuelve. Para cuando la Esencia baja o algo horrible pasa.

Guitarra: Ibanez RGR652AHBF WK D Locrio / Cromática

Cadena de señal

Volume Pedal → Amp (Park 75) + Cab (4x12 Greenback) → Tremolo → Delay → Reverb

Paso a paso

SLOT 1 — Volume Pedal (controlado por EXP 2)
FX TYPE: Volume/Pan → FX MODEL: Volume Pedal
Position: EXP 2 Min: 0% Max: 100%
Controlado por pedal EXP 2. Subí lento para volume swells — las notas aparecen sin ataque de púa. Como esporas brotando del micelio.
SLOT 2 — Amplificador
Tab: AMPS → Modelo: Park 75 (basado en Marshall JMP)
Drive: 45% Bass: 55% Mid: 40% Treble: 50% Presence: 35% Ch. Vol: 45% Master: 60% Sag: 70% Bias: 65% Bias X: 60%
No full distortion — crudo. Mids bajos = hueco, enfermo. Sag MUY alto = lento, decae como algo muriéndose.
SLOT 3 — Cabina
Cab: 4x12 Greenback 25 Mic: 67 Condenser Distance: 60%
Condensador + lejos = difuso, no definido. Como escuchar a través de una pared de micelio.
SLOT 4 — Tremolo
FX TYPE: Modulation → FX MODEL: Opto Tremolo
Speed: 25% Depth: 45% Mix: 50%
Lento, pulsante, como respiración de algo vivo. El hongo respira.
SLOT 5 — Delay
FX TYPE: Delay → FX MODEL: Analog w/Mod
Time: 600ms Feedback: 45% Mod Speed: 55% Mod Depth: 50% Mix: 40%
Repeticiones largas que se acumulan y degradan. Desorientación total.
SLOT 6 — Reverb
FX TYPE: Reverb → FX MODEL: Particle Verb
Decay: 80% Mix: 50% Dwell: 60%
Reverb granular/experimental. Si no te gusta, usa Cave con Decay 85%, Mix 45%.
💡 Técnica: No tocar riffs. Notas sueltas, lentas, con volume swell. Dejar que el delay se acumule. Intervalos disonantes (tritono D→Ab, semitono D→Eb). Largos silencios entre notas. La guitarra no es instrumento melódico aquí — es generador de texturas.

🔊 PRESET 5: "DANZA TRIBAL" — Ibanez Prestige (Staccato tribal / mecánico)

La guitarra como instrumento de percusión. Todo mute, corto, mecánico. Para la Danza de Antenas (conflicto social) y ritmos tribales industriales. Sin melodía, puro ritmo.

Guitarra: Ibanez RGR652AHBF WK D Dórico — ritmos 5/4 o 7/8

Cadena de señal

Gate (tight) → Screamer → Amp (Elektrik) + Cab (4x12 XXL) → EQ → Delay (slap)

Paso a paso

SLOT 1 — Noise Gate (ultra tight)
FX TYPE: Dynamics → FX MODEL: Noise Gate
Threshold: 60% Decay: 0%
Gate ALTO. Las notas mueren instantáneamente. Percusivo puro.
SLOT 2 — Screamer (tighten)
FX TYPE: Distortion → FX MODEL: Screamer
Drive: 5% Bass: 25% Tone: 80% Level: 70%
Casi sin drive. Corta graves, todo "click" y ataque. Brillante, percusivo.
SLOT 3 — Amplificador
Tab: AMPS → Modelo: Line 6 Elektrik (Engl Powerball)
Drive: 55% Bass: 35% Mid: 70% Treble: 65% Presence: 60% Ch. Vol: 50% Master: 55% Sag: 10% Bias: 40% Bias X: 35%
Mids ALTOS = todo ataque. Sag casi CERO = respuesta inmediata. Bass bajo = sin "boom", percusivo.
SLOT 4 — Cabina
Cab: 4x12 XXL V30 Mic: 57 On Axis Distance: 10%
Pegado al cono. Máxima definición. Cada mute se escucha como golpe.
SLOT 5 — EQ Paramétrico
FX TYPE: EQ → FX MODEL: Parametric EQ
LOWS: 28% HIGHS: 62% FREQ: 80% Q: 50% GAIN: 68%
Sin graves (LOWS bajo). FREQ apunta a ~2kHz = puro ataque de púa. HIGHS alto = brillo/click de cuerdas. Todo percusivo.
SLOT 6 — Delay (slap corto)
FX TYPE: Delay → FX MODEL: Digital Delay
Time: 80ms Feedback: 0% Mix: 20%
No es eco — es engrosamiento del ataque. 1 repetición. Suena a máquina duplicada.
💡 Técnica: Todo palm mute agresivo. Notas cortas. Patrones rítmicos en 5/4 o 7/8 (no 4/4 humano). Pensar en la guitarra como un instrumento de percusión. Chugs staccato. La mano derecha manda, la izquierda solo cambia nota cuando el patrón lo pide.

🧪 Expansión: Capa Industrial (Dual Path — Opcional)

Para agregar textura sintética/robótica estilo Godflesh "Streetcleaner" o Ministry, se puede crear un Path B paralelo mezclado muy bajo:

Path B (capa subliminal a -12dB)

B1 — Ring Modulator
FX TYPE: Modulation → FX MODEL: Ring Modulator
Frequency: 180 Hz Mix: 100% Mode: 4-Voice
B2 — Synth
FX TYPE: Filter → FX MODEL: Synth-O-Matic
Mix: 100% Attack: 40% Release: 55% Filter: 60% Freq: 45%
B3 — EQ (limpiar Path B)
FX TYPE: EQ → FX MODEL: Parametric EQ
LOWS: 35% HIGHS: 38% FREQ: 62% Q: 50% GAIN: 60%
MIXER
Path A Vol: 0 dB Path B Vol: -12 dB Pan A: Center Pan B: Center
Path B muy abajo = textura subliminal. Subir a -8dB para efecto más obvio.

🔊 PRESET 3: "AMBAR CLEAN" — Ibanez Prestige (Narrador / Atmósfera)
