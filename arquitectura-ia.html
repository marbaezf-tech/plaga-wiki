📚 Conceptos Clave (para estudiar)

🧬 LoRA (Low-Rank Adaptation)

En vez de entrenar los 8,000 millones de parámetros del modelo, LoRA "pega" adaptadores pequeños (33 millones) en puntos clave de la red neuronal. Es como ponerle lentes al cerebro — no cambias el cerebro, solo filtras lo que ve.

r=16 significa que cada adaptador tiene 16 dimensiones de "memoria nueva". Más r = más capacidad = más VRAM.

📊 Loss (Función de pérdida)

Mide "cuánto se equivoca" el modelo al predecir la siguiente palabra. Loss 2.0 = se equivoca mucho. Loss 0.5 = casi perfecto. El entrenamiento busca bajar este número.

Buen loss final: 0.3-0.8 (depende del dataset). Si baja de 0.1 → está memorizando en vez de aprender (overfitting).

🔢 Quantización (4-bit)

Un número float32 usa 4 bytes. En 4-bit usa solo 0.5 bytes. El modelo se comprime 8x con mínima pérdida de calidad. Por eso Qwen3-8B (que normalmente pide 32GB) cabe en 8GB de VRAM.

NF4 (Normal Float 4-bit) es el formato más eficiente para redes neuronales — optimizado para la distribución estadística de los pesos.

🔄 Gradient Checkpointing

Normalmente el entrenamiento guarda todas las "activaciones" (resultados intermedios) en VRAM para calcular gradientes. Con checkpointing, borra la mayoría y las recalcula cuando las necesita. Ahorra ~40% VRAM pero tarda ~30% más.

🧠 MoE (Mixture of Experts)

En vez de un solo modelo que sepa todo (malo en todo), varios modelos especializados coordinados por un router. Cada pregunta va al "experto" correcto. Como un equipo donde cada uno tiene su rol.

📏 SEQ_LENGTH (Longitud de secuencia)

Cuántos tokens (palabras) puede procesar de una vez durante el entrenamiento. 2048 tokens ≈ ~1500 palabras. Si tu dataset tiene respuestas más largas que esto, se truncan. Más largo = más VRAM pero aprende contextos extensos.

🌡️ Épocas y Learning Rate

Época = una pasada completa por todo el dataset (534 pares). 3 épocas = el modelo ve cada ejemplo 3 veces.

Learning Rate = qué tanto ajusta los pesos por cada ejemplo. Muy alto → oscila y no aprende. Muy bajo → aprende lentísimo. Se va bajando progresivamente (cosine schedule).
